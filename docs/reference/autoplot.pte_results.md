# autoplot.pte_results

Event-study plot for a `pte_results` object. Pre- and post-treatment
periods are distinguished by color.

## Usage

``` r
# S3 method for class 'pte_results'
autoplot(object, ...)
```

## Arguments

- object:

  a `pte_results` object

- ...:

  unused

## Value

a `ggplot` object
