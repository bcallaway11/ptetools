# autoplot.pte_emp_boot

Event-study plot for a `pte_emp_boot` object returned by
empirical-bootstrap estimators (e.g., `cic()`, `qdid()`, `mdid()`). Pre-
and post-treatment periods are distinguished by color.

## Usage

``` r
# S3 method for class 'pte_emp_boot'
autoplot(object, ...)
```

## Arguments

- object:

  a `pte_emp_boot` object

- ...:

  unused

## Value

a `ggplot` object
