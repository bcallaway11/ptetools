# autoplot.dose_obj

Plot dose-specific results for a continuous treatment.

## Usage

``` r
# S3 method for class 'dose_obj'
autoplot(object, type = "att", ...)
```

## Arguments

- object:

  a `dose_obj` object

- type:

  whether to plot `"att"` (default) or `"acrt"`

- ...:

  unused

## Value

a `ggplot` object
